# 页边 · 给生活留一行字

给此刻的自己留一行字。Vite + Vanilla TypeScript + CSS 实现的中文纸条原型，由同路星光制作。白纸、暖灰桌面、细线和少量暖黄均由 CSS / 内联 SVG 表达，没有纸纹贴图、外部字体或图片素材。

## 启动

需要 Node.js 20.19+ 或 22.12+（本次开发环境 Node.js 24.16 / npm 11）。

```sh
cd /Users/orchidxia/Desktop/页边
npm install
npm run dev
```

默认地址为 `http://127.0.0.1:5173`；端口被占用时 Vite 会显示实际地址。浏览器本地存储按 origin 隔离，切换 localhost/127.0.0.1 或端口会得到独立记录。

```sh
npm test          # tsx + node:test，纯逻辑回归
npm run build    # 严格 TypeScript 检查 + Vite 生产构建
npm run preview  # 预览 dist，默认 4173；存储与开发端口隔离
```

不需要环境变量、API Key、数据库、OAuth、服务器业务接口或云资源。已通过 GitHub Pages 公开部署（gh-pages 分支为 `npm run ship` 产出的单文件构建产物）。

## 可以完整体验什么

1. **写一行**：有可访问名称的输入框，三个可选起笔句。最多 200 个 Unicode **码点**，emoji 的代理对不会被截断；中文输入法合成期间暂不截断，合成结束后计数并保存。字素簇（例如家庭 emoji、组合重音）可能占多个码点，非视觉字形计数。
2. **翻到一页**：18 张预置演示纸条（合成内容，README 注明 Demo 数据），按输入命中的预设关键词数量降序排序，同分使用原顺序。解释逐一展示实际命中的词；没有命中时明确说明只是自由翻阅。同频理由由 AI 邮差一次性预生成并固化在源码（`data.ts` 的 `AI_REASONS`，2026-09-15 经 claude-sonnet-5 生成），运行时只读本地文案，无实时 AI 调用或文本外传。
3. **滑卡**：左滑翻过、右滑发起确认；点击或 Enter/空格展开。两枚按钮提供完整替代。Pointer Events 区分纵向滚动与横向拖动，纵向滑动不递出。翻完 18 张显示耗尽态，可重新翻阅同一组，但不恢复今日次数。
4. **递出与批注**：确认弹窗先说明归档方式。实际操作保存输入快照，展示原纸条和预写回条；之后改草稿不改变旧记录。**递出次数不限，想递就递。**每页只保存一次批注，批注草稿自动保存；保存后得到贴纸。
5. **页边册**：查看所有本地发送、待批注、已批注条目，进入详情继续未完成批注。只显示“本地递出页数”和“演示贴纸数”，不虚构真人、实时人数或阅读人数。
6. **读者证**：本机随机编号、创建日期、最后保存的自画像。Canvas 支持五色、两种粗细、橡皮、撤回一笔、清空确认、保存预览。笔画按列表保存、整张重绘到固定离屏画布，ResizeObserver 按屏幕 DPR（最高 3）渲染；无关界面更新不重挂画布。模板栏置顶一张官方形象模板（取自官方《刘看山素材包》，比赛期间授权使用、赛后禁商用），其后是键盘可操作的六种 SVG 简笔画预设；可把当前画布（或已保存的自画像）存为模板，最多 3 个 PNG 模板，只存在本机。未保存自画像时，右上角读者证入口默认显示该官方形象。离开页面或刷新时，对未保存手绘提示确认。只保留最后一张自画像，不做阶段时间轴。
7. **私信**：递出纸条后，回信留在本机私信页。可发文字、图片，也可“发一张简笔画”：内嵌画板（五色、粗细、橡皮、撤回、清空）从空白开始，可选用六种内置模板或自存模板；手绘以本机 PNG 图片递出，选中模板按编号递出。没有表情包或贴纸；画板未发送的笔画在离开页面时丢弃。
8. **支持提示**：有限的高风险词规则暂停普通推荐/批注，显示全国统一心理援助热线 **12356**，立即危险时 **110 / 120**。规则不是诊断，存在误判与漏检；不宣称能识别所有危险，也没有人工实时值守。页面支持随时从页脚进入。
9. **设置与重置**：顶栏“本地演示”按钮说明边界，并通过明确确认重置。只移除 `yebian.demo.v1` 与 `yebian.demo.v2` 两个存储键，不调用 localStorage.clear，不触碰其他项目记录。

## 数据与隐私边界

- 数据保存在此浏览器的 `localStorage`，键名 `yebian.demo.v2`，模式版本 `2`；首次打开会从 `yebian.demo.v1` 严格迁移并保留旧的纸条归档。新增私信/会话也只保存在本机。
- 初始化严格校验版本、字段、长度、日期、纸条 ID、批注一致性和受限自画像格式。自画像模板必须是 PNG data URL、单个小于 1.5MB、最多 3 个；旧版 v2 记录缺少模板字段时按空列表接受。非法 JSON、未知版本和损坏记录被忽略并提示，新输入会保存新版本状态。同一本地日期允许多条递出记录。
- localStorage 不可用、读取异常或超出配额时自动转为本页内存模式，顶部持续提示；刷新/关闭会丢失新内容。不存在云端备份或多设备同步，不应输入敏感隐私。
- 递出**不限次数**，同一天可以连续递出多张，每张各自归档；没有服务器端限制。
- 提交使用同步状态校验防重复；支持 Web Locks 时以同源锁包住重新读取与写入发送/批注。无 Web Locks 时只保证单标签页顺序提交，不能保证竞态下绝对一致。
- 跨标签页 `storage` 事件只提示“载入更新”，不直接替换正在输入的草稿或正在绘画的画布。保存会合并已存在的发送与已完成批注，避免陈旧草稿覆盖归档；草稿、当前匹配和自画像采用最后写入，非协作编辑/冲突解决系统。重置后应关闭或载入更新到其他旧标签页，避免旧标签页再次保存旧状态。
- 文字输出做 HTML 转义。自画像与自存模板只允许受限 PNG data URL 或本地预设标识（预设 0..5），不允许任意外部图片 URL / SVG 字符串。私信里的手绘以压缩后受限的图片 data URL 保存在本机。
- 仅点击公开知乎来源链接时会打开外站；电话链接由设备处理。没有后台网络匹配或 AI 请求。Vite 开发热更新连接不属于业务数据接口。

## 字体来源与授权

界面手写体为两款**站酷免费商用字体**（SIL OFL 1.1），已用 fontTools 子集化后自托管于 `public/fonts/`，**不依赖任何 CDN**（Google Fonts 在国内直连不可用）：

- 站酷快乐体（ZCOOL KuaiLe）→ `zcool-kuaile-subset.woff2`，用于页边批注、按钮、短句
- 站酷庆科黄油体（ZCOOL QingKe HuangYou）→ `zcool-qingke-huangyou-subset.woff2`，用于各级标题

**子集是自动生成的，改文案不用手动维护字体。** `npm run ship` 会先跑 `npm run fonts`：`scripts/subset-font.py` 扫描 `src/**.ts` 与 `index.html` 里出现的所有字符，加上 GB2312 一级汉字（3755 个常用字，覆盖输入框里用户随手敲的句子）重新子集化，并校验界面用字全部命中。源字体放在 `assets/fonts-src/ZCOOLQingKeHuangYou-Regular.ttf`（OFL，取自 google/fonts 官方仓库，仅做子集化、未修改字形）；若该文件缺失，可从 `cdn.jsdelivr.net/gh/google/fonts@main/ofl/zcoolqingkehuangyou/ZCOOLQingKeHuangYou-Regular.ttf` 补回。可复现命令：

```sh
npm run fonts         # 重新生成字体子集
npm run fonts:check   # 只校验当前子集是否覆盖界面用字
```

许可原文见 `public/fonts/OFL-zcool-*.txt`，子集字符清单见 `public/fonts/subset-chars.txt`。字体本身没有的符号（`← → ↗ ↻ ⤢ ·` 等）会回落到系统字体，属预期。正文引用等长句仍使用印刷体宋体栈，遵守"长句印刷体、短句手写体"的可读性规则。

## 音效

`src/sound.ts` 通过 `import.meta.glob` 直接引用项目根目录 `sounds/` 里的用户素材（只读取、不修改），单文件构建时由 `inline.mjs` 内联成 data URI：

- `sounds/点击/`：按钮、链接等点击交互触发。
- `sounds/翻页/`：确认递出纸条时随机选一个播放（页面翻转）。
- `sounds/烟花彩蛋/`：递出后烟花动画触发时随机选一个播放。
- `sounds/环境/`：`rain-on-grass.m4a`（用户素材 MO_TENNY 草地雨声，转 AAC 自托管）——首个用户手势后开始**循环播放**的环境声，音量 = 页脚滑块音量 × 0.3，只做氛围不抢交互音效；源 WAV 保存在 `素材/`。

声音都由点击手势触发，符合浏览器自动播放策略；`sounds/` 缺失或音频不可用时静默降级，不影响交互。
